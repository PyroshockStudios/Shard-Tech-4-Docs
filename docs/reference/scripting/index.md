# Shard Tech 4 C# Script Guide

Welcome to the SDT4 script guide!

The script guide is updated to correspond to the first stable version of Shard Tech 4 (expected to be SDT4.1), and using the oldest supported .NET version (.NET 8 + C# 12.0)

Currently Shard Tech 4 is still in preview, so the guide is subject to changes, however, the guide will remain useful for users.


## Basics

The basics guide covers how to get started making your first game! It covers the Entry Point, Actors, Scenes, Scripts, Basic Biewports, and how to set up your Editor workflow!

## Advanced

The advanced guide covers how to use Shard Tech 4 to the fullest, by expanding upon UI, Networking and Advanced Rendering!

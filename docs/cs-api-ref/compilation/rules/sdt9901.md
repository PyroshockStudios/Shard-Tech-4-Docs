# SDT9901: Bad V-Script Generation

| Property | Value |
| --- | --- |
| **Rule ID** | SDT9901 |
| **Title** | Bad V-Script Generation |
| **Category** | Engine Bug |
| **Severity** | Error |

!!! warning
    This category indicates a possible engine bug, please report bugs to <a href="mailto:support@pyroshockstudios.com">support@pyroshockstudios.com</a>

## Cause
Several causes can be lead to a bad V-Script generation. Most cases can be solved by deleting the script cache, and recompiling, allowing the errors to display in the editor rather than in generated code (e.g. a compiled V-Script references a deleted written function). However in certain rare cases, a compilation bug occurred.

## Rule Description
This error is emitted when errors are found in a generated V-Script file. It is purely to assist finding the cause for the error.

## How to Fix Violations
Before reporting this as a bug, first try deleting the script cache, or recompiling the V-Script. In many situations, the editor will display that a compilation error occurred. If not, please report the bug, including the V-Script asset as well as the generated .g.cs file to <a href="mailto:support@pyroshockstudios.com">support@pyroshockstudios.com</a>
